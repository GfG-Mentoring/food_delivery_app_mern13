# Features V1

1. The food delivery app will have a landing screen which will show famous dishes to order, top brands section and a catalogue of top 10 restaurants near the user. There will be a login/signup button.

Landing screen reference

2. When clicked on the food items, the page filters out restaurants which will serve that specifc food items. Order by minimum distance and max ratings.
3. When user click on restaurants it should show show a restaurant details page that would have restaurant details with food menu and a search bar to find food items. The food items will show image of the food, name, rating and veg and non veg badge next to it.  reference image is in images folder. 
4. Login signup page. Email input, password input and signup.
