# Frontend (React + Vite)

Food delivery customer UI for this monorepo. Project-wide setup, backend instructions, routing overview, and **AI tooling (Cursor)** are documented in the [**repository root README**](../README.md).

## Commands here

```bash
pnpm install
pnpm dev       # http://localhost:5173 — set VITE_API_URL in `.env`
pnpm build
pnpm lint
```
